This section provides detailed step-by-step instructions for running the workshop using the provided Jupyter notebook. You'll work through each component of the system, understanding how the various pieces fit together to create a ETL Observability Solution.

## Accessing the lab environment
Before beginning the implementation, you'll need to access the SageMaker notebook environment that has been prepared for this lab. The notebook contains all the necessary code and detailed explanations for building the Observability Solution.
1. Navigate to the Event outputs section to locate your SageMaker notebook URL. You may need to click on **Monitoring MWAA-Orchestrated ETL Pipelines with Amazon OpenSearch** at the top left of the instructions to access the event outputs screen.

![Workshop Studio event outputs panel showing the SageMaker AI Notebook URL link](/static/notebook_overview/workshop-notebooklink.png)

2. From JupyterLab, launch the Lab-OpenSearch-Observability.ipynb notebook, which contains the ETL Observability Solution implementation.

![Jupyter Notebook list of notebooks](/static/notebook_overview/jupyter.png)

## Notebook structure and overview
The notebook is organized into logical sections that build upon each other to create the complete system. Each section focuses on a specific aspect of the implementation, with detailed explanations and code examples that demonstrate the concepts in practice.

### Working with notebooks
Notebook documents (or "notebooks" all lower case) are documents produced by the Jupyter Notebook App, which contain both computer code (e.g. python) and rich text elements (paragraph, equations, figures, links, etc…).Notebook documents are both human-readable documents containing the analysis description and the results (figures, tables, etc..) as well as executable documents which can be run to perform data analysis. The Jupyter Notebook App is a server-client application that allows editing and running notebook documents via a web browser.

You can find more about notebooks [here](https://jupyter-notebook-beginner-guide.readthedocs.io/en/latest/index.html).
